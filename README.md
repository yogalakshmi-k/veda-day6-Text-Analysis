## Project Description

This project analyzes a given text and calculates the total number of words, characters, vowels, and repeated words using Python. It introduces basic text-processing techniques used in Natural Language Processing (NLP).

## Objectives

- Count the total number of words.
- Calculate the total number of characters.
- Count vowels in the text.
- Identify repeated words and their frequencies.
- Understand basic text-processing techniques.

## Technologies Used

- Python
- Google Colab
- Jupyter Notebook
- `re` module
- `collections.Counter`

## Project Implementation

The project follows these steps:

1. Store a sample paragraph as input.
2. Convert the text to lowercase.
3. Extract words while ignoring punctuation.
4. Calculate the word count and character count.
5. Count vowels using a Python loop.
6. Use `Counter` to identify repeated words.
7. Display the analysis results.

## Sample Output
